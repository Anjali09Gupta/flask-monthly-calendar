# flask-monthly-calendar
🚀This is my first Git Repository.
A simple web application built using Flask that generates a styled calendar based on user-input month and year.
## Features:
• Input month and year
• Displays corresponding calendar
• Clean and colorful UI using HTML & CSS
## Tech Stack:
- Python (Flask)
- HTML
- CSS
##▶️ How to Run:
1. Install Flask
2. Run app.py
3. Open localhost in browser
